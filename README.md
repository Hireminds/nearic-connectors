# Nearic Connectors

Общий коннектор Nearic подключает поддерживаемых агентов к устройствам Nearic через Nearic Service. Первый адаптер рассчитан на Codex Desktop и удалённый Codex CLI. Оба используют одну реализацию авторизации, привязки устройства и обмена с сервисом. Адаптер получает контекст разговора и предоставляет способ установки, подходящий клиенту.

## Состояние

Репозиторий содержит основу разработки с GitHub Spec Kit. Сценарии первого выпуска будут описаны в [спецификациях](specs/README.md).
