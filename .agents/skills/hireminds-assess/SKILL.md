# Исследование идеи Hireminds в чате

Веди workflow `assess` в текущем разговоре по
[общим правилам выполнения](../../../docs/process/chat-workflows.md).
Сначала прочитай эти правила; они объясняют, как получить порядок из YAML и overlays.

Источник процесса: `.specify/workflows/assess/workflow.yml` и его включённые overlays.
Не храни здесь собственную копию этапов.

Вход: `idea` — исходная идея; `slug` — идентификатор исследования.
Используй входные значения и defaults из определения workflow; существенные пробелы уточни.

Применяй официальные скиллы команд из разрешённого workflow. Не запускай отдельную
сессию агента или YAML-runner вместо работы в этом чате.
