# Модель данных коннектора

| Запись | Владелец | Содержимое и инвариант |
| --- | --- | --- |
| Экземпляр коннектора | Хост и сервис | Сервис выдаёт непрозрачный ID экземпляра и фиксирует открытый ключ под разрешением Nearic. Закрытый ключ доступен только доверенной части установки. |
| Разрешение | Сервис | Аккаунт, экземпляр, разрешённые операции и статус. Повторный вход после отзыва создаёт новое разрешение. |
| Адрес разговора | Адаптер и сервис | Тип адаптера, ID экземпляра и точный `threadId` от хоста. Название, рабочая папка и `sessionId` могут измениться или совпасть у разных разговоров. |
| Подтверждение привязки | Сервис | Одноразовое намерение с адресом, экземпляром, разрешением, сроком и выбранным владельцем BOX. Перед фиксацией проверяются актуальные права и поколение предыдущей привязки. Отмена и истечение завершают намерение без переключения. |
| Привязка | Сервис | BOX, адрес, разрешение и монотонное поколение для BOX. Успешное переключение заменяет активную запись атомарно. Отзыв делает связь недействующей для авторизации. |
| Операция статуса | Сервис | Исходные BOX, адрес, поколение, разрешение, дедлайн и корреляционный ID. Переход из ожидания в терминальный результат выполняется один раз. Ответ другого BOX или ответ после терминального результата отклоняется. |

После переключения разрешённая операция в ожидании ещё может завершиться для своего исходного запроса. Предложение при отзыве — закрывать незавершённые операции с отказом. Переподключение BOX само по себе не меняет разрешение или привязку. Данные диалога, секреты BOX и ключи выпуска для этих записей не нужны.
