# ADR 0001: Spec Kit с доменными Living Spec

Статус: принято для процесса разработки. Продуктовая архитектура этим ADR не утверждается.
Дата: 2026-11-19. Уточнено: 2026-11-20.

## Контекст

Нужен воспроизводимый процесс агентской разработки с поддерживаемыми контрактами,
раздельными сценариями функций, ошибок и исследования и понятной проверкой результата.

## Решение

Использовать официальный Spec Kit с интеграцией Codex. Устойчивые доменные спеки
поддерживаются как контракт; план и задачи — производные последнего изменения.
Значимое техническое обоснование сохраняется в ADR и контрактах до замены плана.

Скоуп итерации и существенные решения согласовываются отдельно. Обычные этапы агент
проходит самостоятельно. Процесс соразмерен изменению: функции проходят analyze и converge,
bugfix сохраняет штатный процесс, исследования не запускают реализацию автоматически.

Официальные навыки и шаблоны не форкаются. Для обязательных проверок функций используется
overlay. Его bounded-цикл останавливается при незавершённых задачах; программные тесты
оркестрации выполняются с заглушкой Codex. Presets и сторонние workflow пока не подключены.

Источник порядка и переходов один: YAML-workflow с включёнными overlays. Проектные скиллы
`hireminds-feature`, `hireminds-bugfix`, `hireminds-assess` читают это определение и ведут
его выполнение в текущем разговоре через официальные скиллы. AGENTS направляет к ним,
не дублируя последовательность. Это интерпретация моделью, а не гарантия runner.

Спецификации в `specs/` описывают приложение. Установка и использование инструмента
документируются в руководстве участника без отдельной доменной спеки настройки.

## Последствия

Нужна явная актуализация контрактов. История планов доступна через Git, а не как набор
равноправных источников требований. Исследования и операционные результаты хранятся
в приватной проектной системе. Для обновления существующего домена используется чат;
полный автоматизированный speckit начинает новый комплект. Ограничения модели сохраняются:
успех команды и состояние галочек не доказывают корректность реализации.
