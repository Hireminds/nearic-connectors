# Решения по реализации

В этом разделе хранятся ADR, необходимые для реализации и сопровождения проекта: контекст технического решения, выбранный вариант, последствия и связь со спецификациями.

- [ADR 0001: Spec Kit с доменными Living Spec](0001-spec-kit.md) — процесс разработки.

Утверждённых ADR продуктовой архитектуры пока нет. Предварительные исследования и открытые продуктовые вопросы ведутся во внутренних документах проектной системы; согласованные решения переносятся сюда перед соответствующей реализацией.
